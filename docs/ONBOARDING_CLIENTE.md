## Contenido para el bot

### 1. Presentacion del negocio (1-2 parrafos)
- ¿Que hacen?
- ¿Desde cuando?
- ¿Que los diferencia?

### 2. Servicios / Productos
- Lista completa con descripciones
- Precios (si quiere que el bot los mencione)
- Duracion / tiempos de entrega

### 3. Preguntas frecuentes (minimo 10)
Las preguntas que mas les hacen por WhatsApp.
Ejemplos:
- "¿Cual es el horario de atencion?"
- "¿Cuanto cuesta la consulta?"
- "¿Atienden por obra social?"
- "¿Donde estan ubicados?"

### 4. Horarios
- Dias y horarios de atencion
- Zona horaria
- ¿Atienden feriados?

### 5. Contacto y ubicacion
- Direccion completa
- Email
- Redes sociales
- Link a Google Maps (opcional)

### 6. Proceso de compra / contratacion
- ¿Como contratan un servicio?
- ¿Se necesita turno previo?
- ¿Que metodos de pago aceptan?

### 7. Tono y estilo
- ¿Formal o casual?
- ¿Usan humor?
- ¿Tecnicos o simples?
- ¿Hay palabras o frases que usan mucho?

## Materiales que pueden entregar

- [ ] PDF con servicios y precios
- [ ] Link a su web actual
- [ ] Textos de su web (copiar/pegar)
- [ ] Fotos del local/productos (no se usan en el bot por ahora, pero ayudan a entender)
- [ ] Conversaciones reales de WhatsApp (exportadas) — para extraer FAQs reales

## Reunion sugerida (15-20 min)

1. Explicar como funciona el bot (no adivina, aprende de documentos)
2. Pedirles que envien todo lo de arriba por email/WhatsApp
3. Mostrar un ejemplo de panel admin
4. Definir expectativas: primeros 7 dias con ajustes gratis
5. Confirmar plan y precio
