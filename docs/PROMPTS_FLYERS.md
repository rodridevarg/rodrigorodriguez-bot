## 💡 Tips para textos en los flyers

**Regla anti-ban de Meta (20% máximo de texto):**
- Titular: 3-5 palabras (grande, bold)
- Subtitulo: 1 línea corta
- CTA: 1 botón o URL
- No más de 3 elementos de texto

**Ejemplo de composición:**
```
┌─────────────────────────┐
│                         │
│    [IMAGEN HERMINDA]    │
│                         │
│   "Tu secretaria        │
│    virtual 24/7"         │
│                         │

│                         │
└─────────────────────────┘
```
