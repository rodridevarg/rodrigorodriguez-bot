## 📋 Cómo usar en Kling AI Web

1. Andá a **klingai.com** → Image Generation
2. Seleccioná **Aspect Ratio:** 1:1 (cuadrado) o 4:5 (vertical)
3. Pegá el prompt
4. Descargá la imagen en alta resolución
5. Agregá texto en **Canva** o **CapCut**

## 💡 Tips para Kling AI

**Configuración:**
- **Model:** Kling Image (o el modelo de imagen disponible)
- **Resolution:** 2K (si está disponible)
- **Aspect Ratio:** 1:1 para Feed, 4:5 para Stories

**Después de generar:**
1. Descargar la imagen
2. Abrir en **Canva** o **CapCut**
3. Agregar texto (titular, subtitulo, CTA)
4. **Regla anti-ban:** Nunca más del 20% de texto en la imagen

**Ejemplo de composición:**
```
┌─────────────────────────┐
│                         │
│    [IMAGEN HERMINDA]    │
│                         │
│   "Tu secretaria        │
│    virtual 24/7"         │
│                         │
│   👉 micita.com.ar       │
│                         │
└─────────────────────────┘
```
