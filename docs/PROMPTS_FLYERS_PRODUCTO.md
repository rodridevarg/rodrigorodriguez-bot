# 🎨 Prompts para Flyers — MiCita (Copiar y Pegar en Kling AI)

> Usar con screenshots reales de WhatsApp y Google Calendar

---

## 📋 Cómo usar

1. Andá a **klingai.com** → Image Generation
2. Subí tu screenshot (WhatsApp o Calendar)
3. Copiá y pegá el prompt
4. Descargá la imagen
5. Agregá texto en Canva o CapCut

## 💡 Consejos para mejor resultado

- **Aspect Ratio:** 1:1 (Feed) o 4:5 (Stories)
- **Model:** Usar el modelo de imagen más nuevo disponible
- **Resolution:** 2K si está disponible
- **Después de generar:** Agregar texto en Canva/CapCut
- **Regla anti-ban:** Máximo 20% de texto en la imagen
