## ⚙️ Configuración para Loop Perfecto

| Setting | Valor | Por qué |
|---------|-------|---------|
| **Duration** | 3-5 segundos | Más corto = loop más fluido |
| **Motion** | Low / Subtle | Menos movimiento = menos cortes visibles |
| **Camera** | Static | Sin movimiento de cámara para evitar saltos |
| **Loop** | Seamless / Infinite | Que el movimiento sea cíclico |

---

## 💡 Tips para lograr el loop perfecto

1. **No camera movement** — La cámara debe quedar fija
2. **No character movement** — Herminda debe quedar estática (solo los elementos mágicos se mueven)
3. **Movimiento cíclico** — Las partículas deben flotar en círculos o ciclos repetitivos
4. **Pulso rítmico** — El glow de los iconos debe pulsarse en un beat constante
5. **Duración corta** — 3-5 segundos es ideal para que no se note el corte

## 🎬 Ejemplo de Loop en CapCut (Fallback)

Si la IA no genera un loop perfecto, en CapCut podés:

1. **Importar el video**
2. **Copiar el clip** (Ctrl+C, Ctrl+V)
3. **Invertir el segundo clip** (Efectos → Reversa)
4. **Unir ambos clips**
5. Resultado: El video va de A→B y luego B→A, creando un loop perfecto
